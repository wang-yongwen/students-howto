# 如何修改学位论文

 - 2015年10月12日 22:32 发表于https://weibo.com/p/1001603897250379091556

不少同学写完学位论文后，一遍又一遍地看，每看一遍都想改点东西，不知道什么时候才算改完，而这些修改对提高论文的质量也不见得有多少帮助。如何有效地修改学位论文是每一位即将毕业的同学都关心的问题。

本文提出学位论文的三遍修改法，阐述了为什么要修改三遍的道理，以及每一遍修改关注什么要素。本文的目的不是教你如何写学位论文，更不是教你如何做课题研究，而是在你写完学位论文初稿之后，通过三遍修改，将论文达到较高质量的定稿状态。

1. 为什么要三遍修改

论文是呈现你研究工作的载体，而你的工作要通过三个层次才能呈现出来。第一层是论文的结构，也就是章节划分及标题的取定，这是你研究工作逻辑关系的呈现。第二层是论文的语言，也就是遣词造句，这是你研究工作内容的呈现。第三层是论文的排版，也就是字体、图表、标点等，这是你论文的呈现，也就是你研究工作内容的呈现的呈现。读者或评阅人阅读你的论文，也是透过这三个层次才能了解你的工作。

这三个层次彼此不太相关，而在一轮检查中同时顾及这三个层次很困难的，而一遍遍的检查也不能保证完整地覆盖。所以你最好检查三遍，每遍侧重一个层次。

2. 第一遍修改是调整结构

这一遍修改的目的是使论文结构清晰严谨。主要任务有两个，一是检查章节划分，二是确定章节标题。具体的方法有：

 - 增加：若已有章节不足以支撑论文的结论，则应该增加章节，必要时补充研究工作。
 - 删除：若已有章节与论文主题或彼此之间逻辑不一致，或给自己挖坑又填不平，则应该删除。
 - 排序：若章节逻辑关系混乱，则应该按空间顺序、时间顺序、因果顺序、递进顺序等比较清晰的顺序重新调整。
 - 重组：若章节之间关系不平等，或体量不相当，则应该将章节合并、或拆分，使之平衡。

你可以使用以下检查清单来确认这一遍修改的质量：

 - 每一章的第一段是不是对本章内容的概括
 - 每一章的最后一段是不是对本章内容的总结
 - 每一章的各节是否属于同一逻辑范畴
 - 每一章的各节是否按照逻辑顺序组织
 - 每一节的各小节是否属于同一逻辑范畴
 - 每一节的各小节是否按照逻辑顺序组织
 - 章节标题是否准确体现了本章节的思想
 - 同一级别的章结标题风格是否一致

3. 第二遍修改是润色语言

这一遍修改的目的是使论文语句流畅，消除病句。具体的方法有：

 - 增加：需要的句子词语
 - 删除：不需要的词语或句子
 - 调整：词语或句子的顺序
 - 替换：使用更合适的词语或句子

你可以使用以下检查清单来确认这一遍修改的质量：

 - 每一段是不是都有主题句
 - 每一句话是不是消除了语病
 - 每一句话与论文的其他语句的观点有没有冲突
 - 每一句话是否准确表达了你想表达的内涵
 - 每一句话是不是多余的
 - 专业术语的使用是否规范
 - 全文是否只使用同一个术语表达同一个概念

4. 第三遍修改是校对版面

这一遍修改的目标是使论文拼写正确、标点正确、图表规范、版面美观。主要任务包括但不限于：

 - 中文打字是否正确，如错字、重字、漏字
 - 标点使用是否正确，如逗号、句号、句号、问号
 - 是否做过自动拼写检查
 - 英文的大小写、时态、语态、单复数等是否正确
 - 全角和半角的使用风格是否一致
 - 图、表编号和引用是否正确
 - 字体使用是否一致

这一遍修改和论文内容没有关系，可以请别人帮忙。

5. 小结

这三遍修改基本上覆盖了论文呈现的三个层次，从而能让论文更好地呈现你的工作。
